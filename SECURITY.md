# Security Policy

USB snapshots and details generated by this project may contain device serial numbers, PnP instance IDs, device paths, and driver information. Use synthetic data when reporting an issue, or redact these identifiers first. Do not post raw snapshots, complete local logs, or credentials in public issues or pull requests.

## Private reporting

Once private vulnerability reporting is enabled, use the repository's **Security → Advisories → Report a vulnerability** entry to provide reproduction steps, impact, and de-identified examples. Until that entry is available, wait for the maintainers to provide a private contact method; do not disclose vulnerability details publicly.

The public repository exists. As checked on 2026-10-14, GitHub private vulnerability reporting is not yet enabled. Maintainers must enable it and confirm that these instructions work.
